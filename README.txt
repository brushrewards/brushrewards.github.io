# Brush Rewards Website

A free, static, mobile-first website for the Brush Rewards early-stage app.

## Files
- index.html — website content
- style.css — design and responsive layout

## Before publishing
1. Replace `partners@brushrewards.example` in `index.html` with the real partnership email.
2. Add real app screenshots when ready.
3. Do not claim any brand partnership until it is confirmed.
4. Publish using a free static host such as Cloudflare Pages or GitHub Pages.

The site is intentionally static so it can be hosted for free.
